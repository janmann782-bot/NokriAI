Самая дешевая подтвержденная китайская текстовая модель в просмотренной таблице - ds/deepseek-v4-flash ($0.0125/1M по текущей странице). GLM 4.7 слабее флагмана, но по AnyModel дороже ($0.015/1M), поэтому нельзя обещать снижение расходов. У прямого Z.ai GLM 4.5 Flash бесплатен, но это не означает наличие и бесплатность у AnyModel. Исходная просьба о еще более дешевой китайской модели через AnyModel пока не имеет подтвержденного варианта.

DeepSeek сообщает, что старый V4 Flash снят, а его прежние прямые API-имена обслуживает V4.1 Flash. AnyModel продолжает показывать V4 Flash. Его реальную upstream-версию мы не проверили. Прежний аудит не дает аттестации конкретной модели. Поле model ответа логируется, но не доказывает идентичность.

Для неподтвержденного Flash тариф null, а не фиктивный 0. Для Qwen/Pro/GLM сохранены тарифы текущей открытой страницы AnyModel: $0.03/$0.025/$0.075 за 1M входных или выходных токенов соответственно. Дата проверки записана в pricing_checked. Тарифы можно установить в JSON input_price/output_price (USD за 1M). Только при наличии usage обоих типов рассчитывается cost. Это оценка по сообщенным токенам, не подтверждение фактического списания AnyModel. Тарифы из разных страниц/прошлых сессий различались, автоматически умножать неизвестные credits нельзя.

Смена соответствия не требует перезаписи кода:

1. `/modelconfig flash` - скопируйте текущий JSON
2. Измените api_model/name/тарифы в копии
3. `/setmodel flash {полный JSON}` - модель автоматически выключается
4. `/catalog` - обновите доступность
5. `/enable flash 1` - явно утвердите и включите

Значения provider=anymodel и base_url=https://anymodel.org/v1 фиксируются валидатором. api_model допускает только префиксы ds/deepseek-, qwen/qwen, glm/glm-. Включение требует наличия точного ID в каталоге за последние 24 часа. Никакого fallback на другую модель.

Это документальная проверка каталогов. Авторизованная генерация и проверка ответа по каждому ID требуют актуального ключа AnyModel и выполняются после настройки.

С v0.2 тарифы используются для единого денежного бюджета пользователя. Счетчики по числу сообщений и квоты конкретной модели удалены. `/price MODEL INPUT OUTPUT` задает цены USD/1M токенов без редактирования JSON. Нулевой тариф допустим только как осознанная настройка владельца, неизвестный тариф не трактуется как 0. Перед включением модели тариф обязателен.

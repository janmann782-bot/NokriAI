# Аудит источников и телефонной системы

## Подтверждено

Сопоставлены оба приложенных архива. Пакет Nokri содержит только 2 текстовых документа с правилами и предварительными кодами, исходного кода бота в нем нет. Архив Аурелии содержит 1 495 файлов, включая вики, DOCX, PDF, карты и языковые материалы. Программные файлы из архива не исполнялись.

Прочитаны правила Nokri целиком, правила сильмира из DOCX, правила новосильмира из TXT, образцы словарей. Словарные строки индексируются раздельно по нормам. Просмотрена политическая карта 2061 размером 7 680 × 4 320. Проверены статьи Кефирстана, Каменного Моста, Вордсфалии, Нидросии, Дервеснии, Медии, Саргатийской Федерации и Шавермастана в относящейся к задаче части. Остальной текст автоматически извлечен и проиндексирован, это не ручная проверка каждой строки.

+201 и структура зон 1xx/2xx/3xx/4xx закреплены прямыми требованиями автора. Другие коды не утверждены. Их предварительный исходник сохранен без изменений в docs/nokri_phone_codes_v2.txt. Бот не считает этот файл публичным реестром.

## Противоречия и неопределенность

- Вордсфалия расположена сразу в Эниварре и Саргатии, большая территория на карте находится на западном континенте. Предварительный +102 нельзя утверждать только потому, что у страны есть владения западнее Кефирстана. Для основного международного кода нужна выбранная основная зона, автономии и заморские территории могут получать внутренние диапазоны
- В архивной статье Кефирстана площадь 2 320 032 км². В контексте поздней работы есть другое значение. Бот не получает автоматически ни одну спорную площадь как текущий подтвержденный факт
- Статья Каменного Моста содержит численность за 2062, а текущая дата бота в день сборки 14.11.2061 по Москве. Такие сведения не выпускаются в публичный контекст
- Общий архив содержит земные сравнения планеты и подробные будущие хроники. Сырой корпус нельзя целиком передавать модели
- Документы без явной даты публикации не позволяют восстановить момент общественной доступности автоматически. Все сырье остается restricted/draft. Даже предположительная поздняя дата 31 декабря максимального года документа не делает его публичным

## Предложения, не канон

В config/phone_plan.json закреплен +201. Внутренние 21/22/23 для Кефирии/Творограда/Молозори и 91 для мобильной сети сохранены как draft. Остальные предварительные коды можно расширять после проверки географии. Скрипт не присваивает новые коды автоматически.

Бытовые объекты Nokri остаются generated, не approved. Перенос в канон требует отдельной явной редакторской операции, в боте такой автоматической операции нет.
